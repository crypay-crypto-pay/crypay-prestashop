# crypay-prestashop

Crypay payment module for PrestaShop 8.x and 1.7.x. Accept BTC, ETH, USDC, EURC and more via [Crypay](https://crypay.com).

> 🚧 Skeleton — CRY-785 in progress. BG agent extends with HMAC verification + admin tab.

## Live demo

https://presta-demo.crypay.com — admin at /admin-demo (login: demo@crypay.com / demodemo123). Resets every 30 min.

## Compatibility

- PrestaShop 1.7.8 and 8.x (8.0 / 8.1 / 8.2)
- PHP 7.4 / 8.0 / 8.1 / 8.2

## Install

1. Download release ZIP from GitHub Releases.
2. PrestaShop admin → **Modules → Module Manager → Upload a module** → choose `crypay.zip`.
3. Configure: enter API key + Gateway URL.
4. Crypay appears in checkout payment options.
